# Plan 06-01: PDF Vector Geometry & OperatorList WASM Extractor

## Objective
Establish the core vector geometry and low-level graphics extraction layer that inspects raw PDF drawing operations (strokes, fills, line segments, font matrices, clipping paths) and outputs an exact coordinate map for Document Layout Analysis (DLA).

## Context & Architecture
Standard PDF text extraction (e.g. `getTextContent()`) only returns isolated strings and approximate glyph coordinates, completely blind to:
- Table border lines and grid rectangles.
- Background cell shading fills and colored banner boxes.
- Floating vector shapes, rules, dividers, and diagram arrows.

By interfacing with the raw PDF graphics pipeline (`page.getOperatorList()`) and compiling a lightweight geometric vector parser in WebAssembly:
1. Every vector path (`OPS.constructPath`, `OPS.stroke`, `OPS.fill`, `OPS.rectangle`) is captured as exact $(x_1, y_1) \to (x_2, y_2)$ line segments and bounding boxes.
2. Intersecting horizontal and vertical lines are automatically grouped into table cell boundaries with mathematical certainty.
3. The extracted vector geometry is unified with the text layer into a comprehensive **Page Geometry Map**.

## Tasks
1. **Build `pdfVectorExtractor.js`:**
   - Parse `page.getOperatorList()` to capture vector operations (`OPS.moveTo`, `OPS.lineTo`, `OPS.rectangle`, `OPS.stroke`, `OPS.fillPath`, `OPS.eoFill`).
   - Transform device-space coordinates through the current transformation matrix (CTM) into standard point coordinates (pt).
2. **Build Line & Rectangle Grid Classifier:**
   - Filter and cluster horizontal line segments ($H$) and vertical line segments ($V$).
   - Identify closed grid cells and background shading rectangles for exact table and callout detection.
3. **Unify Vector Geometry with Text Layer:**
   - Align text items inside their true enclosing vector cell rectangles.
   - Attach authentic background fill colors directly from vector fill operations.
4. **Unit & Benchmark Tests:**
   - Validate line extraction on Section 04 (Cluster Matrix), Section 05 (Balance Sheet), Section 10 (8-column table), and Section 18 (Feature Matrix).
   - Ensure zero performance degradation on multi-page files.
