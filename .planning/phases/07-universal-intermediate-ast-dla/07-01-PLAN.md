# Plan 07-01: Universal Intermediate AST & Multi-Format DLA

## Objective
Construct the format-agnostic Universal Intermediate Abstract Syntax Tree (AST) and Document Layout Analysis (DLA) engine that decouples raw PDF layout extraction from output file formats, enabling 100% conversion accuracy across Word (`.docx`), Excel (`.xlsx`), and PowerPoint (`.pptx`).

## Context & Architecture
Currently, `convertClient.js` maps PDF text lines and tables directly into Word OOXML elements (`Paragraph`, `Table`, `TextRun`). This direct coupling restricts output to Word and cannot easily generate multi-sheet Excel workbooks or coordinate-accurate PowerPoint slides.

By constructing a **Universal Document AST**:
1. **Extraction & Layout Analysis (DLA)** analyzes PDF text items and vector geometry, segmenting them into an abstract hierarchy: `Document` -> `Page` -> `Block` (`Paragraph`, `Table`, `Callout`, `CodeBlock`, `SlideShape`).
2. **Target Emitters** consume this unified tree independently:
   - **Word Emitter:** Serializes `Paragraph`, `Table`, and `Callout` into flowing OOXML documents.
   - **Excel Emitter:** Extracts all `Table` nodes, preserving typed numeric cells, currency formats, and multi-sheet workbooks.
   - **PowerPoint Emitter:** Projects `SlideShape` nodes and 2D bounding boxes into slide layouts.

## Tasks
1. **Build `documentAst.js`:**
   - Define node types: `DOCUMENT`, `PAGE`, `PARAGRAPH`, `TEXT_RUN`, `TABLE`, `TABLE_ROW`, `TABLE_CELL`, `CALLOUT`, `CODE_BLOCK`, `SHAPE`.
   - Node factory functions with schema validation and cloning/serialization utilities.
   - Tree traversal / visitor utilities for format emitters.
2. **Build `documentLayoutAnalysis.js`:**
   - XY-cut recursive spatial decomposition to partition pages into coherent reading-order blocks.
   - Vector table binding: binds extracted vector lines and rectangles to table cells, extracting raw numerical values (`1250000`) alongside formatted text (`$1,250,000`).
   - Running header and footer isolation.
   - High-level `buildDocumentAst(pageLayouts, vectorGeometries)` orchestrator.
3. **Build Comprehensive Test Suite `documentAst.test.js`:**
   - Test AST generation on single-column, two-column, table, and callout layouts.
   - Verify numeric extraction for spreadsheet emission.
   - Verify tree visitor traversals.
4. **Verification:**
   - Run `npm run test:word` and `npm run build`.
