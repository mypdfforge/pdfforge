# Plan 08-01: High-Accuracy DOCX & Multi-Sheet XLSX Emitters

## Objective
Implement dedicated Word (`.docx`) and Excel (`.xlsx`) emitters consuming the Universal Document AST from Phase 07, delivering commercial-grade reflowed Word documents and multi-sheet accounting workbooks directly in the browser with zero cloud dependencies.

## Tasks
1. **Build `docxEmitter.js`:**
   - Traverses the Universal AST `DocumentRoot`.
   - Maps `ParagraphNode` and `TextRunNode` to `docx.Paragraph` and `docx.TextRun`.
   - Maps `TableNode` to `docx.Table` with authentic vector fills and column widths in twips.
   - Maps `CalloutNode` to native shaded callout boxes.
   - Serializes to `.docx` Blob via `Packer.toBlob`.
2. **Build `xlsxEmitter.js`:**
   - Extracts all `TableNode` instances from the AST.
   - Generates multi-sheet Excel workbooks using `exceljs` or `xlsx`.
   - Writes typed numerical cells (`rawValue`) with accounting format codes (`$#,##0.00`, `0.0%`).
   - Applies table header fill styling and autowidth column sizing.
   - Serializes to `.xlsx` Blob.
3. **Integrate with `convertClient.js`:**
   - Expose `pdfToExcel(file, onProgress)` using the Universal AST and `xlsxEmitter.js`.
4. **Build Unit Tests (`emitters.test.js`):**
   - Verify DOCX and XLSX generation from AST with typed cells.
5. **Verification:**
   - Run `npm run test:word` and `npm run build`.
