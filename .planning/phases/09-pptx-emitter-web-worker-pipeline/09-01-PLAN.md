# Plan 09-01: Editable PPTX Slide Emitter & Background Web Worker Pipeline

## Objective
Implement a commercial-grade PowerPoint (`.pptx`) emitter consuming the Universal Document AST with real, editable text boxes, native slide tables, and vector background shapes, supported by an asynchronous background Web Worker pipeline.

## Tasks
1. **Build `pptxEmitter.js`:**
   - Traverses the Universal AST `DocumentRoot`.
   - Converts each `PageNode` into a PowerPoint Slide with matching aspect ratio.
   - Maps `ParagraphNode` into editable text frames (`slide.addText`) with font size, bold, color, and coordinates.
   - Maps `TableNode` into editable slide tables (`slide.addTable`) with authentic vector fills and borders.
   - Maps `ShapeNode` and `CalloutNode` into 2D vector shapes.
   - Serializes to `.pptx` presentation Blob.
2. **Build `conversionWorkerClient.js`:**
   - Asynchronous worker dispatcher with progress reporting.
3. **Integrate with `convertClient.js`:**
   - Expose `exportAstToPptx` and update `pdfToPptx` with AST-driven editable slides.
4. **Build Unit Tests (`pptxEmitter.test.js`):**
   - Verify slide generation, text boxes, and table rows from AST.
5. **Verification:**
   - Run `npm run test:word` and `npm run build`.
