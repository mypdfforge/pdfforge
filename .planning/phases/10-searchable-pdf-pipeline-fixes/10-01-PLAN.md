# Plan 10-01: Duplication Elimination & Unicode TrueType Font CMap Embedding

## Goal
Fix the two most critical defects in PDFForge's Searchable PDF generation pipeline:
1. **The "Echo Chamber" Duplication Bug**: Prevent text from duplicating when processing documents that already have a native or legacy OCR text layer.
2. **The "Question Mark" / Mojibake Encoding Bug**: Replace the WinAnsi-limited standard font (`Helvetica`) with `@pdf-lib/fontkit` and a true Unicode TrueType font (`LiberationSans-Regular.ttf`), ensuring proper UTF-8 CMap encoding for Greek, math symbols (`μ`, `σ`), sub/superscripts (`H₂SO₄`, `E = mc²`), and diacritics.

## Problem Analysis

### 1. Text Layer Duplication
- **Current Code**: `buildSearchablePdf(originalPdfBytes, pagesResults)` loads the incoming PDF via `PDFDocument.load(originalPdfBytes)` and draws invisible text (`drawText`) on top of the existing pages.
- **Root Cause**: If the input PDF already contains selectable text, `pdf-lib` retains the existing text stream operators (`BT ... ET`) and appends the new OCR text operators, creating two superimposed text layers.
- **Solution**:
  - Provide a clean page slate strategy: for searchable PDF generation from scanned pages, each page can be composed of the high-res canvas render image + the single, authoritative OCR text layer.
  - Or strip existing text objects from content streams prior to injecting the OCR layer.

### 2. Unicode CMap & Mojibake (`?` / stripped chars)
- **Current Code**: 
  ```javascript
  const font = await pdfDoc.embedFont(StandardFonts.Helvetica)
  ...
  catch (err) {
    const sanitizedText = line.text.replace(/[^\x20-\x7E]/g, ' ')
  }
  ```
- **Root Cause**: `StandardFonts.Helvetica` only supports WinAnsiEncoding (ASCII 32–126). Any non-ASCII character throws an error, causing the catch block to wipe out non-ASCII glyphs.
- **Solution**:
  - Install `@pdf-lib/fontkit` in `frontend/`.
  - Register `pdfDoc.registerFontkit(fontkit)`.
  - Fetch and embed `LiberationSans-Regular.ttf` (already in `frontend/public/wasm/docx2pdf/fonts/LiberationSans-Regular.ttf`, cached via `fetchWithCache`).
  - Render all Unicode characters through the embedded TrueType font with full UTF-8 CMap mapping.
