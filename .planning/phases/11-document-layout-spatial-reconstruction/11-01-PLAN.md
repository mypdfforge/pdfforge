# Plan 11-01: Multi-Column XY-Cut Segmentation, Code Block Pitch & Header/Footer Masking

## Goal
Implement document spatial reconstruction and reading order sequencing for PDFForge's OCR pipeline:
1. **Multi-Column XY-Cut Block Segmentation**: Detect vertical gutters to read multi-column documents sequentially (down column 1, then column 2) instead of interleaving text across margins.
2. **Code Block Whitespace & Indentation Preservation**: Detect monospace/code regions and compute exact indentation spaces from bounding-box X-offsets so Python/code blocks retain authentic syntax structure.
3. **Running Header & Footer Zone Isolation**: Tag and isolate recurring top/bottom margin text (top/bottom ~8%) so they do not bleed into the body text flow.

## Implementation Details

### 1. Spatial Layout Segmentation (`frontend/src/utils/ocrLayoutAnalysis.js`)
Create a dedicated layout analysis module that processes raw PaddleOCR bounding boxes:
- **Header/Footer Separation**: Lines with center Y within top 8% or bottom 8% of page are tagged as `header` / `footer`.
- **XY-Cut Column Detection**:
  - Analyze horizontal distribution of bounding boxes to detect vertical gutters (separating columns).
  - Cluster body lines into columnar blocks.
  - Sort blocks by column X-coordinate, and within each block, sort lines by top-to-bottom Y-coordinate.
- **Code Block Indentation Detection**:
  - For lines detected as monospace/code (or lines with significant left-indent variations), compute `Math.round((line.box.minX - block.minX) / avgCharWidth)` and prepend exact indentation spaces.

### 2. Integration with `paddleOcr.js` & `OCRToolPage.jsx`
- Pass raw OCR results through `segmentPageLayout(lines, pageWidth, pageHeight)`.
- Use the segmented blocks to produce clean, naturally-ordered extracted text.
- Use sorted and indentation-preserved lines in `buildSearchablePdf` so text selection and `Ctrl+F` follow column flow.
