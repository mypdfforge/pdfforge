# Plan 12-01: Table Structure Reconstruction, Semantic Tagging & Confidence Scoring

## Goal
Complete the final phase of Milestone 3:
1. **Tabular Structure Reconstruction**: Detect multi-column and multi-row tabular grids (Sections 04, 05, 10, 23) by clustering row lines by `yCenter` and grouping into columns by X-coordinates, outputting structured Markdown tables in the Extracted Text view.
2. **Semantic Element Classification**: Classify lines as Section Headings, Admonition Callouts (`[NOTE]`, `[WARNING]`, `[CRITICAL]`), Code Blocks, Tables, or Paragraphs.
3. **Word & Page Confidence Scoring**: Compute real-time recognition confidence scores from PaddleOCR probabilities, displaying an overall document accuracy score and highlighting low-confidence regions.

## Implementation Details

### 1. Table Detection & Row-Column Alignment (`ocrLayoutAnalysis.js`)
- **Row Clustering**: Group lines within a candidate block that share overlapping vertical ranges (`|yCenter1 - yCenter2| < 0.6 * lineHeight`).
- **Column Detection**: If multiple consecutive rows have 2+ horizontally spaced cells at consistent X intervals, classify the cluster as a `TableBlock`.
- **Markdown Table Assembly**: Format detected table cells into aligned Markdown tables:
  ```markdown
  | ID | Hostname | Zone | CPU% | RAM% | Disk% | Latency | Status |
  | --- | --- | --- | --- | --- | --- | --- | --- |
  | SRV-101 | us-east-1.internal | zone-B | 35% | 52% | 39% | 1.6ms | OPERATIONAL |
  ```

### 2. Semantic Classification (`ocrLayoutAnalysis.js`)
- Detect Heading 1 / Section Titles based on height ratio (`height > 1.3 * medianHeight`).
- Detect Admonitions: lines starting with `[NOTE]`, `[WARNING]`, `[CRITICAL]`, `[SUCCESS]`.
- Detect Code blocks: clusters with monospace keywords or relative indentations.

### 3. Confidence Metrics & UI Badging (`OCRToolPage.jsx` & `paddleOcr.js`)
- Compute average confidence score across all pages: `(sum(line.mean) / totalLines) * 100`.
- Display a quality badge in `OCRToolPage.jsx`:
  - `High Accuracy (≥ 95%)`
  - `Good Quality (85%–94%)`
  - `Review Advised (< 85%)`
