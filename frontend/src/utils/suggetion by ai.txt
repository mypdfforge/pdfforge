PDFForge v2 Redesign Master Prompt
Project Vision

Redesign PDFForge into a modern AI-powered PDF workspace inspired by Claude, Linear, Cursor, Raycast, Notion, and Vercel.

The current product already contains a strong collection of PDF tools, but the experience still feels like a traditional "tool directory" where users choose a tool first and then upload files.

The new vision is:

PDFForge is not a collection of PDF tools.

PDFForge is a unified workspace where users upload documents and perform everything from a single interface.

The redesign should focus on:

Better first impression
Cleaner information architecture
Workspace-first workflow
AI-native experience
Premium SaaS aesthetics
Reduced cognitive load
Faster user actions
Modern developer-tool design language
